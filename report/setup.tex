\chapter{Experimental Setup}
\label{ch:setup}

\section{Compute and software}

The run metadata of the main experiments records PyTorch 2.14.1 and no CUDA device, so training and evaluation ran on the CPU of a laptop-class machine, in 32-bit floating point and without mixed precision. This corrects an earlier statement that the experiments used mixed-precision training on a GPU. Audio was decoded with SoundFile and resampled with librosa; MP3 coding for the degradations uses FFmpeg. The full-data reference runs of Chapter~\ref{ch:prelim} were configured for GPU feature extraction. Seeds were fixed (42) and each configuration was trained once.

\section{Training budget}

Each of the three main models was trained on the subset of 13{,}800 training clips described in Section~\ref{sec:data}, for at most 20 epochs with early stopping (patience 5). The baseline reached its best validation score at epoch 20, the last epoch allowed, so it had probably not converged. The FT-RCL run stopped after epoch 12 and its best checkpoint is from epoch 7; STAR-Edge used all 20 epochs. With one seed per configuration, differences between models include training variance that the bootstrap intervals of Chapter~\ref{ch:results} do not capture, since those intervals describe only the sampling of evaluation clips.
